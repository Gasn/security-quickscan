# Manual Handoff Acceptance

Copying a FactoryOS prompt into an external tool is a manual handoff. It does not
mean FactoryOS submitted a job to that tool.

FactoryOS has not submitted a job for this external tool run and has no visibility
into the run, its intermediate state, or its results unless a human shares them
back through the normal review process.

Humans review the resulting pull request and decide whether to merge it.
